# ⚡ Inventory Intelligence Agent
**Empowering local Indian retail stores with Enterprise-Grade AI.**

## 🚀 The Problem
Local kirana and retail stores lose thousands of rupees weekly to stockouts and over-ordering. They lack the data forecasting tools that large supermarket chains use to optimize their supply chains.

## 💡 Our Solution
The Inventory Intelligence Agent acts as a 24/7 AI supply chain manager. Store owners simply upload their weekly sales data, and our platform uses **IBM Granite AI** to:
1. Forecast exact demand based on current stock.
2. Generate automated, supplier-ready purchase orders.
3. Alert the owner to critical low-stock items in real-time.

## 🛠️ Tech Stack
* **Frontend:** Vanilla HTML, CSS, Bootstrap 5, JavaScript (Dark Mode enabled)
* **Backend:** Python (Flask/FastAPI)
* **AI Engine:** IBM Granite SDK
* **Data Processing:** Pandas / Python
